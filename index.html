2. Chi tiết kỹ thuật

Lỗ hổng nằm ở hàm parse_metadata() trong file image_loader.c:

void parse_metadata(char *input) {
    char buffer[256];
    strcpy(buffer, input);  // Classic buffer overflow
    process(buffer);
}
